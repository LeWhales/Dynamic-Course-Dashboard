Render, filter, and summarize a course dashboard from an array of objects.
Requirements
    Use semantic starter HTML and a separate JavaScript file loaded with defer.
    
    Use the names: index.htmp, style.css, app.js for your program
    
    Render at least eight records with createElement and textContent.
    
    Provide empty-state and invalid-data messages.
    
    Use classes and data attributes instead of inline style changes.
    
    Include a screenshot of the DOM tree and a short explanation of the render pipeline.

Minimum test set

    full data
    empty array
    record with missing optional field
    selector failure
